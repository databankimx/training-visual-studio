# Checklist: branches and stashing

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You created a branch from the branch dropdown in the status bar.
- [ ] You switched between main and your feature branch, and saw the file change.
- [ ] You stashed uncommitted changes from the Git menu.
- [ ] You applied a stash to bring the changes back.
- [ ] You completed the homework, and checked that main did not change.

Chapter 15 covers pushing, pulling, and syncing.
