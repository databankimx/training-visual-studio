# 4. Windows, Layout, and Finding Your Way

Visual Studio is made of windows. The editor is the large one in the middle, and around it sit the Solution Explorer, the Error List, the Output window, and others. This chapter shows you how to find any command by name with Command Search, how to pin, float, and dock those windows so they sit where you want them, how to search the text of every file in the solution with Find in Files, and how to put the layout back to normal when you move things out of place.

Keep the practice solution from Chapter 3 open while you work through the lessons.
