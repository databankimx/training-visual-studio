# Chapter summary

Remember these as you work through the rest of the course:

- Command Search, opened with {{Ctrl+Q}}, finds commands, settings, and windows by name.
- Each tool window can be pinned, set to Auto Hide, floated, or docked. The pushpin controls the first two.
- Find in Files, opened with {{Ctrl+Shift+F}}, searches every file in the solution. Window, then Reset Window Layout, puts the windows back.

```quiz
Which shortcut opens Find in Files, to search every file in the solution?
○ Ctrl+F
→ Ctrl+F opens the Find box for the file you have open. Find in Files is Ctrl+Shift+F.
◉ Ctrl+Shift+F
→ That is Find in Files. It searches the text of every file in the solution.
○ Ctrl+T
→ Ctrl+T opens Go to All, which finds files by name, not text inside them.
```

```quiz
What does a pushpin turned sideways on a window's title bar mean?
○ The window is floating
→ A floating window is a separate window. The sideways pushpin means something else.
◉ The window is set to Auto Hide
→ Yes. The window tucks itself away at the edge, and comes back when you point at its tab.
○ The window is closed
→ A closed window does not leave a pushpin on the screen. The sideways pushpin means Auto Hide.
```

```quiz
Which menu command puts every window back where it started?
○ File, then Close Solution
→ That closes the solution. It does not move any windows.
○ Edit, then Undo
→ Undo reverses a text change. It does not move windows.
◉ Window, then Reset Window Layout
→ That puts each tool window back in its original place.
```
