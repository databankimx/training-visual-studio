# Checklist: windows and layout

Work through this list before you go on. Each item is something you can see on the screen.

- [ ] You opened a command with Command Search, using {{Ctrl+Q}}.
- [ ] You can tell Command Search, with {{Ctrl+Q}}, apart from Go to All, with {{Ctrl+T}}.
- [ ] You can say what the pushpin on a window does, and what Auto Hide means.
- [ ] You floated a window, and docked it again.
- [ ] You searched for Total with Find in Files, using {{Ctrl+Shift+F}}, and opened a result.
- [ ] You reset the window layout with Window, then Reset Window Layout.

Chapter 5 covers typing, selecting, and moving code.
