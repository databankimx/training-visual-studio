# Resetting the window layout

Visual Studio lets you move almost every window. Over time, that freedom can leave the screen in a state that is hard to work in. A window is floating off the edge of the monitor, or the editor is squeezed into a narrow column between tool windows, or a window you need has been hidden. When that happens, reset the layout to bring everything back to its starting positions.

## Resetting the layout

Choose Window, then Reset Window Layout. Visual Studio moves each tool window back to the place it had when Visual Studio was installed, and it sets each one to its default state. The windows return to the positions you saw when you first opened the solution.

Figure 4.1 shows a floated window beside the editor, which is one of the states a reset will undo.

## What the reset does and does not change

The reset changes only where the windows sit. Your files, your solution, and your settings stay as they are. Your color theme stays the same, and so do your keyboard shortcuts. You will not lose any code, so it is safe to reset whenever you want a clean start.

## When to use it

Reset when:

- A window has disappeared and you cannot find it with Auto Hide or a tab.
- You have floated and docked several windows and the editor looks cramped.
- You want to compare the default layout with your own, and then go back.

Check the screen after the reset, since every window moves at once. If you want to keep the layout you have built, do not reset until you have finished arranging the windows.

## Try it

1. Float the Error List by dragging its title bar out of the docked area.
2. Choose Window, then Reset Window Layout.
3. Check that the Error List is back in its docked position.
