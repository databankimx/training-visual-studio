# Command Search

Visual Studio has hundreds of commands, and most of them live in menus that are deep and easy to lose. Command Search gives you a shortcut to any of them. Press {{Ctrl+Q}}, type part of the name, and pick the result from the list. Command Search also finds settings and windows, so it is the place to go when you do not know where something is.

## Opening Command Search

Press {{Ctrl+Q}}. A box opens at the top of the window. Start typing straight away. The list below the box updates with each letter you type, so you can stop as soon as the command you want is at the top.

## Try it

1. Press {{Ctrl+Q}}, then type Solution Explorer. Choose the result. The Solution Explorer comes to the front, even if it was hidden.
2. Press {{Ctrl+Q}}, then type theme. You will see the color theme setting you changed in Chapter 1. Choose it, and the Options dialog opens to that page.
3. Press {{Ctrl+Q}}, then type build solution. The result shows the command and its shortcut, which is a good way to learn the keys over time.

## Command Search or Go to All?

The two boxes look alike, so it is easy to mix them up.

- **Go to All**, opened with {{Ctrl+T}}, finds files by name.
- **Command Search**, opened with {{Ctrl+Q}}, finds commands, settings, and windows.

If you want a file, press {{Ctrl+T}}. If you want to do something to the code or the window, press {{Ctrl+Q}}.

## Moving through the results

Use the arrow keys to move up and down the list. Press {{Enter}} to run the command you have highlighted. Press {{Esc}} to close the box without running anything.

## Common mistake

Typing a whole sentence rarely helps. Command Search matches the words in the name of a command, so a short phrase such as solution explorer or reset layout works better than a description of what you want to happen.
