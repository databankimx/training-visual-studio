# 8. Refactoring Safely

Refactoring changes the structure of code without changing what it does. You rename a method so its name says what it does. You pull a repeated calculation into a method of its own. You tidy the file so every line follows the same style. Visual Studio can do each of these for you, and it updates every place that depends on the change, which is what makes the work safe.

The lessons use the practice solution. The homework creates a small file in the Pricing project, asks you to rename a method used in three places, and to pull out a repeated expression. Delete the file when you finish.
