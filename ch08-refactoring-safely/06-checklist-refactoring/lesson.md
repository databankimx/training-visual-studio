# Checklist: refactoring safely

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You renamed a symbol with {{Ctrl+R}}, then {{Ctrl+R}}, and every use changed with it.
- [ ] You previewed a rename from the drop-down in the Rename box.
- [ ] You extracted a block of code to a new method with {{Ctrl+.}}.
- [ ] You ran Code Cleanup with {{Ctrl+K}}, then {{Ctrl+E}}, and checked the changes.
- [ ] You completed the homework, and deleted Refactor.cs afterward.
