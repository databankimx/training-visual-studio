# 2. Creating Your Accounts

Visual Studio and the later chapters use two accounts. Your Microsoft account signs you in to Visual Studio. Your GitHub account holds the practice repository, where you push changes, open pull requests, and use Copilot. Chapter 1 skipped the sign-in prompt, so this chapter sets up both accounts and creates the practice repository you will break on purpose later.

If you already have a personal Microsoft account or a personal GitHub account, use it and skip its sign-up steps. Check only that its settings match what this chapter describes. If you do not have one, go through the steps in order. Nothing here costs money.

> **Personal accounts only:** the course uses a personal GitHub account for all of its practice. Company accounts cannot create repositories directly on GitHub Enterprise, so the practice repository has to live in a personal account. Use yours for every step in this chapter and the rest of the course.
