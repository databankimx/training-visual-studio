# Creating the practice repository

A repository is a project folder that Git keeps a history for, and that GitHub stores for you. The practice repository is a small C# solution that the course uses for every hands-on lesson. You will change its files, commit them, and break things on purpose, so the course gives you your own copy to ruin.

## Start from the template

Open the practice template at https://github.com/databankimx/training-visual-studio-practice. It is a repository the course keeps, and you create your own copy of it from there. Your copy does not change the template.

Figure 2.6 shows the Use this template button.

![Figure 2.6 - Use this template button](images/ch02-use-this-template.png "width=50%")

*Figure 2.6 - Use this template button*

Select Use this template, and then Create a new repository. GitHub asks for a name. Use something that tells you what it is, such as training-visual-studio-practice. Leave the other settings as they are.

Figure 2.7 shows the form.

![Figure 2.7 - Create a repository from the template](images/ch02-create-from-template-form.png "width=75%")

*Figure 2.7 - Create a repository from the template*

Choose Private if you want your practice work out of public view. Private is a good choice for this course.

Your new repository now lives under your account, at an address with your username in it. Chapter 3 opens it in Visual Studio, and Chapter 14 uses it for your first commits.

> **Do not use a company repository:** the exercises change files, create branches, and sometimes leave them in a mess. Keep them in your personal practice repository, never in a repository your team uses.
