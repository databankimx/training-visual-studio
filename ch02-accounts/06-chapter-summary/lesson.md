# Chapter summary

Your Microsoft account signs you in to Visual Studio, your GitHub account holds your practice repository, and your commits use the noreply address. Keep these in mind:

- Practice runs in a personal account only. Company accounts cannot create repositories directly on GitHub Enterprise.
- Commits record your name and email, so use the noreply address from GitHub's Emails settings.
- Create the practice repository from the template, and keep it private.

```quiz
Why does the course use a personal GitHub account for the practice repository?
◉ Company accounts cannot create repositories directly on GitHub Enterprise.
→ That is the reason. The practice repository has to live in a personal account.
○ Personal accounts are faster to sign in to.
→ Speed is not the reason. The reason is where repositories can be created.
○ GitHub Enterprise does not allow two-factor authentication.
→ Two-factor authentication is available on GitHub Enterprise. The reason is repository creation.
```

```quiz
Which address should you use with git config user.email?
○ Your GitHub username
→ A username is not an email address, and Git will not accept it as one.
◉ The noreply address that GitHub shows in your Emails settings
→ That address keeps your real email out of every commit.
○ Your work email address
→ Your work address would be published with each commit you push.
```

```quiz
Which account signs you in to Visual Studio?
```
