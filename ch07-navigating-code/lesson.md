# 7. Navigating Code

A solution holds many files, and a method you want to understand may be called from three places in two projects. Navigating code means moving from a name to its definition, from a definition to its callers, and back again, without searching by hand. This chapter covers Go to Definition, Find All References, Peek Definition, the reference counts shown above methods, and the Object Browser for types you did not write.

The lessons use the practice solution, with PriceCalculator in the Pricing project as the main example. The homework asks you to follow the references to one method and report what you find.
