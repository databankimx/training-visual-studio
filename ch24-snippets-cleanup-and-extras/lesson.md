# 24. Snippets, Code Cleanup, and Extras

Some code is the same every time you write it. A property with a backing field, a test method with its attributes, a block you always wrap the same way. Visual Studio can insert that code for you from a snippet, and it can tidy a file for you with Code Cleanup. Quick Launch finds a setting or a command when you cannot remember where it lives.

This chapter covers inserting a snippet, writing your own, running Code Cleanup by hand and on save, and using Quick Launch. The homework uses all of them on the practice solution.

Cleanup applies the style rules that you and your team have chosen. Before you commit a file that cleanup changed, read the change. Cleanup is a tool that does what it is told, and a clean diff is one you have checked.
