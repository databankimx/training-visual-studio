# 10. Running and Debugging

Building proves that the code compiles. Running it proves that it does what you meant. Visual Studio can run a program with or without the debugger attached. With the debugger, you can pause the program at a line you choose, read the values of its variables, and move through the code one step at a time. This chapter covers starting a program, breakpoints, stepping, the Locals and Watch windows, and the Immediate window.

The lessons use PriceReport, the console program in the practice solution. Before you start, make PriceReport the startup project. Right-click it in the Solution Explorer, and choose Set as Startup Project. The name of the startup project appears in bold.
