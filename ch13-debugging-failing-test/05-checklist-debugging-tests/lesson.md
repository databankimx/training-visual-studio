# Checklist: debugging a failing test

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You started one failing test under the debugger with Debug Test(s).
- [ ] You read the values of variables in the Locals window at a breakpoint.
- [ ] You added a condition to a breakpoint, and found it in the Breakpoints window.
- [ ] You worked out an expected answer by hand before you looked at the code.
- [ ] You completed the homework, and corrected the wrong test.
- [ ] You deleted the files you added for this chapter, unless your instructor asked you to keep them.
