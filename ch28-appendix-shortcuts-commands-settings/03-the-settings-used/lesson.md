# The settings used

These are the settings the course changes. Each one lists the Options page where you find it, and the chapter that uses it.

| Setting | Where to find it | Chapter |
| --- | --- | --- |
| Keyboard mapping scheme | Options, Environment, Keyboard, Mapping scheme | Chapter 23 |
| Find a command to rebind | Options, Environment, Keyboard, Show commands containing | Chapter 23 |
| Shortcut for a command | Options, Environment, Keyboard, Press shortcut keys | Chapter 23 |
| Code Cleanup profile on save | Options, Text Editor, Select a Code Cleanup profile to run on save | Chapter 24 |
| Code Cleanup profiles | Broom button on the status bar, Configure Code Cleanup | Chapter 24 |

Settings can be saved to a file and loaded again with Import and Export Settings, in the Tools menu. Read a settings file before you share it, because it can record folder paths and account names.
