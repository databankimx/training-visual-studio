# The shortcut table

The official one-page sheet is [Visual Studio keyboard shortcuts (PDF)](../docs/visual-studio-keyboard-shortcuts.pdf). It opens in your default PDF app.

Each row is one shortcut the lessons use. The first-used column gives the chapter that first teaches it, so you can go back to the full explanation.

| Shortcut | Action | First used |
| --- | --- | --- |
| {{Ctrl+Q}} | Quick Launch: search for a command or setting | Introduction |
| {{Enter}} | Accept the highlighted choice or confirm a dialog | Introduction |
| {{Ctrl+;}} | Move the cursor into the Solution Explorer search box | Chapter 3 |
| {{Ctrl+Shift+A}} | Add a new item to the project | Chapter 3 |
| {{Ctrl+T}} | Go to All: find a file or item by name | Chapter 3 |
| {{Ctrl+F}} | Find in the current file | Chapter 4 |
