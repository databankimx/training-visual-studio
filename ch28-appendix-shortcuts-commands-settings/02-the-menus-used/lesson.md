# The menus used

The commands below are the ones the lessons open. Each one lists where to find it and the chapter that first uses it. Menu names follow the default layout.

| Command or window | Where to find it | First used |
| --- | --- | --- |
| Options | Tools menu | Chapter 23 |
| Import and Export Settings | Tools menu | Chapter 23 |
| Code Snippets Manager | Tools menu | Chapter 24 |
| Solution Explorer | View menu, or {{Ctrl+Alt+L}} | Chapter 3 |
| Error List | View menu, or {{Ctrl+\}} then {{E}} | Chapter 9 |
| Output window | View menu, or {{Ctrl+Alt+O}} | Chapter 26 |
| Test Explorer | Test menu, or {{Ctrl+E}} then {{T}} | Chapter 11 |
| Debug Test(s) | Right-click a test in Test Explorer | Chapter 12 |
| Breakpoints window | Debug menu, under Windows | Chapter 12 |
| Immediate window | Debug menu, under Windows | Chapter 10 |
| Manage Extensions | Extensions menu | Chapter 22 |
| Reset Window Layout | Window menu | Chapter 26 |
| Run Code Cleanup | Broom button on the file's status bar | Chapter 24 |
| New Branch | Branch name in the status bar, on the Local tab | Chapter 14 |
| Account menu, Add another account | Account icon, top right | Chapter 19 |
| Copilot Chat window | Copilot icon, top right | Chapter 20 |
