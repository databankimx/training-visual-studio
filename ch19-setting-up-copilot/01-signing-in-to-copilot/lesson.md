# Signing in to Copilot

Copilot uses your GitHub account, the same account that holds the practice repository. You add that account to Visual Studio from the user menu, which is the account icon at the top right of the window. The Copilot menu does not sign you in.

Click the account icon. The menu shows the Microsoft account you set up in Chapter 2, with its Account settings link and an Add another account button. Choose Add another account. Figure 19.1 shows the list of account types, and GitHub is the second.

![Figure 19.1 - Choosing GitHub in the Add another account list](images/ch19-add-github-account.png "width=50%")

*Figure 19.1 - Choosing GitHub in the Add another account list*

Choose GitHub. Visual Studio opens a page in your browser. If the page asks you to sign in, sign in with your GitHub username or email address and your password. Then choose Continue, to authorize Visual Studio to use the account.

Return to Visual Studio. If a Use Copilot for Free prompt appears, read it before you choose anything. It offers the free Copilot plan, and Chapter 19 lesson 2 explains how to see which plan the account is on.

## Try it

1. Click the account icon at the top right of the window, and read the menu.
2. Choose Add another account, then GitHub, and sign in on the page that opens.
3. Return to Visual Studio, and open the account icon again to check that the GitHub account is listed.
