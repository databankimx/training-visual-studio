# Chapter summary

Remember these when you work with Copilot:

- Press {{Tab}} to accept an inline suggestion, and {{Esc}} to reject it. Read every suggestion before you accept it.
- Open the Chat window from the Copilot icon, and select a method before you ask about it.
- Check every claim in an answer against the code and the tests.
- Choose the least powerful chat mode that does the job.

```quiz
Which key rejects an inline suggestion without changing the file?
○ Tab
→ Tab accepts the suggestion, and it becomes part of the file.
◉ Esc
→ Yes. The grey text disappears, and the file stays the same.
○ Ctrl+Z
→ Ctrl+Z undoes a change. It does not reject a suggestion that is still shown.
```

```quiz
You want an answer about one method. What should you do first?
◉ Select the method, then ask about it
→ Yes. The selected text goes with the question, so the answer points at the right lines.
○ Ask about the whole solution
→ A broad question gets a broad answer that is hard to check.
○ Turn off suggestions
→ Turning off suggestions does not affect the Chat window.
```

```quiz
A chat answer says a method sorts the prices. The code has no sort. What should you do?
○ Accept the answer, because it sounds right
→ A claim that has no matching line is wrong, however confident it sounds.
○ Add a sort to the method to match the answer
→ Changing the code to match a wrong answer is the mistake to avoid.
◉ Mark the claim as wrong, and check the code and tests
→ Yes. Compare each claim with the lines, and record the ones that do not match.
```
