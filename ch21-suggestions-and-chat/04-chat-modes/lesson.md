# Chat modes

The Chat window can work in more than one mode. The mode sets how far Copilot can go. In a question mode, Copilot answers and changes nothing. In an edit mode, Copilot proposes changes to the files you select, and you accept or reject each one. In an agent mode, Copilot can take several steps, such as running a build, and then report what it did.

Choose the least powerful mode that does the job. For an explanation, a question mode is enough. For a small change, an edit mode lets you review each line before it is saved. Use an agent mode only when the task has several steps, and read what it did, step by step, before you accept the result.

The names of the modes and the controls for choosing them can change between versions of Visual Studio. Check the mode control in the Chat window, and read what it says before you send a request.

## Try it

1. Open the Chat window, and find the control that shows the current mode.
2. Read the description of each mode, if the control shows one.
3. Leave the mode set to the question mode for the homework.
