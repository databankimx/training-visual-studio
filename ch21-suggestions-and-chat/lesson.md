# 21. Suggestions and Copilot Chat

Chapter 20 set up Copilot. This chapter uses it. Copilot works in two ways. Inline suggestions appear in the editor as you type, and you accept, reject, or cycle through them. Copilot Chat is a window where you ask questions about your code and get answers in plain language.

Both ways produce text that looks confident. A suggestion can compile and still be wrong, and a chat answer can describe code that is not there. The rule from Chapter 20 applies here: read every suggestion and every answer, and check it against the code and the tests before you rely on it.
