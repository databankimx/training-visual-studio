# The Copilot Chat window

Copilot Chat is a window for questions. Open it from the Copilot icon at the top right of the window, and choose Open Chat. Figure 21.2 shows the Chat window beside the editor, with a question typed in its box.

![Figure 21.2 - The Copilot Chat window beside the editor](images/ch21-copilot-chat.png "width=50%")

*Figure 21.2 - The Copilot Chat window beside the editor*

The Chat window keeps a history of your questions and its answers, in the order you asked them. You can start a new conversation when you change topics, so an answer about one method does not mix with another. Chat answers are text, so they can include code blocks. Read a code block as a suggestion, not as a change to your files.

Chat sees the file you have open and any text you select. A question about the open file gets a better answer than a general one, because the answer can point to the actual lines.

## Try it

1. Open the Copilot menu, and choose Open Chat.
2. Find the question box at the bottom of the Chat window.
3. Type a short question, such as What does PriceCalculator do?, and read the answer. Do not paste any secrets or customer data into the box.
