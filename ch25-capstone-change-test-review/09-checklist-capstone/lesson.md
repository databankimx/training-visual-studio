# Checklist: capstone

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You opened the practice solution, and confirmed the branch was main with no changes.
- [ ] You created a branch, and checked the status bar showed it.
- [ ] You ran the tests, and read the expected and actual values for the failing test.
- [ ] You debugged the failing test, and found the line that returned the wrong value.
- [ ] You fixed the code, and every test passed.
- [ ] You committed the change with a clear message, and pushed the branch.
- [ ] You opened a pull request, and wrote a description a reviewer can check.

Chapter 26 covers what to do when things go wrong.
