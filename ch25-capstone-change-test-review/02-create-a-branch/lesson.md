# Create a branch

Your team has a rule that you never fix a problem directly on main. So you give the fix its own room, called a branch. Changes on a branch do not touch main until someone merges them, so you can experiment, make mistakes, and throw the branch away if it goes badly.

Chapter 14 covered creating a branch. Use the same steps here. Click the branch name in the status bar, choose New Branch on the Local tab, and type a name such as fix-min-price. Check that Visual Studio creates the branch from main, and switches to it.

Names are short, lowercase where your team uses lowercase, and say what the change does. fix-min-price tells a reviewer more than changes or test.

> **Check the name in the status bar.** Before you edit anything, confirm the branch is the one you created. Working on the wrong branch is easy to miss, and annoying to untangle.

## Try it

1. Click the branch name in the status bar, and choose New Branch on the Local tab.
2. Type fix-min-price, and create it.
3. Check that the status bar now shows fix-min-price.
