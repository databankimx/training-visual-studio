# Open a pull request

A pull request asks your team to review your branch before it reaches main. Chapter 17 covered the steps. Once the branch is on GitHub, a Compare and pull request banner appears on the repository page. Choose it, check the branch names, and write the description.

The description is the most important part for a reviewer. Say what was wrong, what you changed, and how you checked it. The homework below asks you to write it.

## Try it

1. Open the repository page on GitHub, and choose Compare and pull request.
2. Check that the base is main, and the compare branch is fix-min-price.
3. Read the Files changed tab, and confirm it shows one changed line.
