# 5. Typing, Selecting, and Moving Code

Most of your time in Visual Studio goes to typing, selecting, and rearranging code. This chapter covers the keys that make those jobs faster: undo and redo, selecting text and blocks, moving and duplicating lines, commenting code out, and formatting a whole file so the indentation is consistent.

The practice solution from Chapters 3 and 4 is your workspace. Where a lesson changes a file, use Ctrl+Z to undo the change, or restore the file from Git once you have the Git lessons later in the course. Nothing here is permanent until you save.
