# Chapter summary

These keys cover most of the editing you will do in this course:

- Undo with {{Ctrl+Z}}, and redo with {{Ctrl+Y}}.
- Select a word with {{Ctrl+W}}, and a block with Alt and a drag.
- Move a line with {{Alt+Up}} or {{Alt+Down}}, and duplicate it with {{Ctrl+D}}.
- Comment with {{Ctrl+K}}, then {{Ctrl+C}}, and uncomment with {{Ctrl+K}}, then {{Ctrl+U}}. {{Ctrl+/}} toggles comments on and off, and the toolbar has buttons for both.
- Format a file with {{Ctrl+K}}, then {{Ctrl+D}}.

```quiz
Which key combination formats the whole file?
○ Ctrl+Shift+B
→ Ctrl+Shift+B builds the solution. It does not change the layout of the code.
◉ Ctrl+K, then Ctrl+D
→ Yes. Press the two keys one after the other to format the file.
○ Ctrl+F
→ Ctrl+F opens the Find box. Formatting is Ctrl+K, then Ctrl+D.
```

```quiz
Which keys move the current line up one line?
○ Ctrl+Z
→ Ctrl+Z undoes the last change.
◉ Alt+Up
→ Yes. Alt+Up swaps the line with the one above it. Alt+Down moves it down.
○ Ctrl+Y
→ Ctrl+Y redoes a change you have undone.
```

```quiz
What does Alt and a mouse drag select?
○ One word
→ To select one word, put the cursor on it and press Ctrl+W.
◉ A rectangular block of text across several lines
→ Yes. A block selection lets you edit the same column on several lines at once.
○ The whole file
→ To format or select the whole file, use the Format Document shortcut or Select All.
```
