# Checklist: merge conflicts

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You created a conflict by changing the same line on two branches.
- [ ] You found the conflict in the Git Changes window.
- [ ] You read the conflict markers, and said which side is which.
- [ ] You used the merge editor's checkboxes to choose the result, and clicked Accept Merge.
- [ ] You committed the merge with a message that explains the choice.
- [ ] You completed the homework, and removed Labels.cs when you finished.
