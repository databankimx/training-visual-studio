# The history view

The Git Repository window shows the history of the repository. Open it from the View menu, then Git Repository, or from the Git menu. The tab at the top of the editor shows the name of the repository and its branch, such as practice (main), once it is open.

The window lists the commits on the current branch, newest first. Each row shows the commit message, the author, the date, and a short hash, which is the commit's identifier. Select a commit to see the files it changed in the details pane. The branch name appears at the top, so you know which history you are reading.

The history is the same for everyone who has the repository. Your commits from Chapters 13 to 17 are there, along with the commits from the pull request you closed without merging, if you ran that homework, which stays in its own branch.

## Try it

1. Open the Git Repository window from the View menu.
2. Find the commit with the message Add a comment to the report, from Chapter 13.
3. Select it, and read the file names in the details pane.
