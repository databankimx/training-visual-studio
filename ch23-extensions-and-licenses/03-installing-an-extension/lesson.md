# Installing an extension

Install an extension only after you have checked its publisher, its license, and what it does. If your organization keeps a list of approved extensions, check the list first. An extension that is not on an approved list needs approval before you install it.

On the details page, choose Download, or the install button, then choose Modify, or Install, if the Visual Studio installer asks to make the change. Visual Studio often asks you to close and restart before the extension works. Save your work first. Once Visual Studio restarts, the extension appears on the Installed tab.

Installing an extension changes your copy of Visual Studio, not your code. The extension does not add files to the practice repository, but it can add menus, windows, and analyzers that change what you see.

## Try it

1. Open an approved extension, or ask your instructor which extension to use for the homework.
2. Install it, and restart Visual Studio if it asks.
3. Open the Installed tab, and check that the extension is listed.
