# Chapter summary

Remember these about extensions:

- Find extensions in Manage Extensions, on the Browse tab. The Installed tab shows what is already on your computer.
- Check the publisher, the license, and the purpose before you install. A copyleft or unclear license is a reason to escalate.
- Disable an extension to turn it off, and uninstall it to remove it.

```quiz
Where do you find extensions that you can install?
◉ The Browse tab of Manage Extensions
→ Yes. It searches the Visual Studio Marketplace.
○ The Installed tab
→ The Installed tab lists extensions already on your computer.
○ The Output window
→ The Output window shows messages, not extensions.
```

```quiz
An extension has a copyleft license, and you cannot tell what it allows. What should you do?
○ Install it, because it is popular.
→ Popularity does not answer the license question.
○ Install it, and remove it if it causes trouble.
→ Install first is the wrong order. Check the license before you use it.
◉ Escalate the question before you install it.
→ Yes. Copyleft or unclear licenses must be escalated before use.
```

```quiz
What is the difference between disabling and uninstalling an extension?
○ Disabling deletes it, and uninstalling keeps it.
→ It is the other way round.
◉ Disabling keeps it on your computer, and uninstalling removes it.
→ Yes. Disable when you may need it again, and uninstall when you will not.
○ There is no difference.
→ The two actions leave different results on your computer.
```
