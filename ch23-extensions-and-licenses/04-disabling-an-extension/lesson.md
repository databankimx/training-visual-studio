# Disabling an extension

Disabling an extension turns it off without removing it from your computer. Use it when an extension conflicts with something else, or when you want to see how Visual Studio behaves without it. Open Manage Extensions, select the extension on the Installed tab, and choose Disable. Restart Visual Studio if it asks.

To turn it back on, select the disabled extension, and choose Enable. The extension comes back with the settings it had before.

To remove an extension completely, uninstall it from the same window. Uninstalling removes it from your computer, and it leaves no copy behind. Disabling is the right choice when you may need the extension again, and uninstalling is the right choice when you are sure you will not.

## Try it

1. Open Manage Extensions, and select an extension on the Installed tab.
2. Choose Disable, and restart Visual Studio if it asks.
3. Open Manage Extensions again, select the extension, and choose Enable.
