# What Copilot sends, and the settings

To suggest code, Copilot sends part of the code around your cursor to GitHub's service. That usually includes the file you are editing and some nearby files. Suggestions come back from the service, and Visual Studio shows them in the editor. Your code is not in the suggestion unless the suggestion uses it, and nothing is sent until you type or ask for a suggestion.

What the service keeps, and how long it keeps it, depends on your plan and your organization's settings. Read GitHub's current documentation for Copilot before you use it on work you cannot share. This is the reason the rule at the start of this chapter asks you not to enter secrets or customer data into an AI tool. A secret you type into a comment may be sent, even if you never intend to use it as code.

The settings that control suggestions are in the Options dialog, under the GitHub section, in the Copilot page. The page lets you turn on or off automatic suggestions as you type, and choose which kinds of suggestion appear. Changes take effect straight away, and you can change them back at any time.

## Try it

1. Open the Options dialog from the Tools menu, and find the Copilot page under GitHub.
2. Read the options, but change nothing yet. The homework asks you to change one.
