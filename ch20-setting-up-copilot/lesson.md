# 20. Setting Up Copilot

GitHub Copilot is an AI assistant built into Visual Studio. It suggests code as you type, and it can answer questions about the code you have open. This part of the course shows how to set it up, what it sends to GitHub, and how to control it. Later chapters use it for suggestions and chat.

Before you use Copilot in this course, read this rule. Use only the AI tools and accounts your organization has approved. Do not enter customer data, passwords, secrets, or confidential project details into an AI tool. Treat every suggestion as untrusted until you have read it, understood it, built it, and tested it. The code you deliver is yours, whoever or whatever wrote the first draft. A suggestion that looks polished is not evidence that it is correct.

This rule comes from the development rules for custom code at DataBank. If you are working outside DataBank, follow the rules your own organization has set.

If you want a more in-depth exploration of AI-assisted coding, the [AI-Assisted Coding tutorial](https://github.com/databankimx/training-ai-assisted-coding) goes further than this part of the course. It is optional, and you can work through it at any time, before or after this chapter.
