# Rebinding a shortcut

A rebind gives one command a different key combination. You can rebind any command that has a shortcut, and you can give a command a shortcut when it has none.

**Note:** The Keyboard page has not yet moved to the VS 2026 Options window. It opens in a separate window, the older Options dialog, so the page looks different from the rest of the Options pages. The steps are the same.

Open the Tools menu, choose Options, and then choose Environment and Keyboard. At the top of the page, the Show commands containing box filters the list. Type part of the command's name, such as SolutionExplorer, and the list narrows. Type it without a space. With a space in the name, the search returns nothing. to the matching commands. Select the command you want.

Figure 23.2 shows the page with a search result. The shortcuts the command already has are listed with it, and the Press shortcut keys box is where you enter the new one.

![Figure 23.2 - The Keyboard page with a search result](images/ch23-keyboard-search.png "width=75%")

*Figure 23.2 - The Keyboard page with a search result*

Click in the Press shortcut keys box, and press the combination you want. If the combination is already in use, the page tells you which command uses it, and you choose a different combination. If it is free, click Assign, and then choose OK.

Test the new shortcut before you move on. Remember that the change is saved to your computer. It does not change the shortcut for anyone else.

To remove a binding you added, select the command again, and click Remove. To undo every keyboard change you have made, choose Reset All. Reset All affects all of them, not just the one you are working on, so use it with care.

## Try it

1. Open Environment and Keyboard in Options, and type SolutionExplorer in the Show commands containing box, with no space.
2. Select the Solution Explorer command, and read its current shortcut. Do not change it yet.
3. Choose Cancel to close the dialog.
