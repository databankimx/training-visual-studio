# Checklist: settings and shortcuts

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You opened the Options dialog and used its search box to find a setting.
- [ ] You exported your settings to a file, and read the file before you did anything else with it.
- [ ] You found the Mapping scheme list, and left it as Visual Studio Default, or chose another on purpose.
- [ ] You rebound a command, used the new shortcut, and put the default back.
