# Chapter summary

Keep these in mind for the rest of the course:

- Type a dot to open the completion list, and use {{Ctrl+Space}} to open it again.
- Parameter info appears inside a method's parentheses. Bring it back with {{Ctrl+Shift+Space}}.
- A red wavy underline is an error. Read its message by hovering over it, or find it in the Error List.
- Press {{Ctrl+.}} on a problem to open the Quick Actions menu.

```quiz
Which key combination opens the Quick Actions menu on a problem?
◉ Ctrl+.
→ Yes. Put the cursor on the problem, and press Ctrl+. to open the fixes.
○ Ctrl+Space
→ Ctrl+Space opens the completion list. Quick Actions use Ctrl+.
○ Ctrl+Shift+B
→ Ctrl+Shift+B builds the solution. Quick Actions use Ctrl+.
```

```quiz
What does a red wavy underline mean?
○ A suggestion you can ignore
→ Suggestions use a different color. A red underline is more serious than that.
○ A bookmark you added yourself
→ Bookmarks do not add underlines to the code. A red underline marks an error.
◉ An error: the code will not build as written
→ Yes. Hover over the underline to read the message.
```

```quiz
Which key combination shows the parameter info for a method call?
◉ Ctrl+Shift+Space
→ Yes. Press it inside the parentheses to bring the parameter info back.
○ Ctrl+Space
→ Ctrl+Space opens the completion list. Parameter info uses Ctrl+Shift+Space.
○ Tab
→ Tab inserts the highlighted item in a completion list. It does not show parameter info.
```
