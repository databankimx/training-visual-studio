# 6. IntelliSense and Quick Actions

Visual Studio reads your code as you type it. It knows which types, methods, and variables are available at the cursor, so it can offer the names you need, show the parameters a method expects, underline mistakes before you build, and often suggest the fix. The features that do this are called IntelliSense and Quick Actions. This chapter shows you how to use them without losing your place in the code.

The lessons use the practice solution. The homework adds one file to the Pricing project, and it asks you to delete that file when you finish.
