# 22. Extensions and Licenses

Extensions add features to Visual Studio. One might add a new code analyzer, a formatter, or a window for a tool your team uses. The Visual Studio Marketplace lists thousands of them, and anyone can publish one. That makes an extension a piece of software you bring into your environment, so it needs the same checks as a library.

Before you install an extension, check who published it and what its license allows. The development rules for custom code at DataBank say that third-party and open-source software must have a license that permits closed-source commercial use, and that copyleft or unclear licenses must be escalated before use. Developers must not add a dependency just because an AI tool suggested it. The same care applies to extensions.

This chapter shows where to find extensions, how to read their publisher and license, how to install and disable them, and how to remove them.
