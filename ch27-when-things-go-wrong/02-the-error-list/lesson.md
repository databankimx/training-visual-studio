# The Error List

The Error List collects errors, warnings, and messages from your code and from the editor. Chapter 9 used it to find build errors. When Visual Studio itself seems to misbehave, the Error List can show the messages it logged while you worked.

Open it from the View menu, choose Error List, or press {{Ctrl+\}} then {{E}}. Use the Errors, Warnings, and Messages buttons at the top to filter the list. Double-click an entry to go to the line it names.

If the list is empty, that does not mean nothing went wrong. Check the Output window too, because some problems are reported there and not in the list.

## Try it

1. Open the Error List with {{Ctrl+\}} then {{E}}.
2. Click the Warnings button to filter the list, then click it again to turn the filter off.
3. Close the Error List with {{Esc}}, or with its close button.
