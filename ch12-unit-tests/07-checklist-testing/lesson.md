# Checklist: unit tests

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You found the Test menu, and read the shortcuts for Run All Tests and Test Explorer.
- [ ] You opened Test Explorer with {{Ctrl+E}}, then {{T}}.
- [ ] You built the solution with {{Ctrl+Shift+B}}, and ran all the tests with {{Ctrl+R}}, then {{A}}.
- [ ] You ran one test by right-clicking its name.
- [ ] You read a failure message in the detail pane, and found the failing line.
- [ ] You explained why a passing test does not prove that the code is correct for every input.
- [ ] You completed the homework, and added a boundary test.

Chapter 13 covers debugging a failing test.
