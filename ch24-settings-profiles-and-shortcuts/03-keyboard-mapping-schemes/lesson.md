# Keyboard mapping schemes

A keyboard mapping scheme is a named set of shortcuts. Visual Studio ships with several. The one this course uses is Visual Studio Default, which is the set the earlier chapters taught. Other schemes copy the shortcuts of older versions of Visual Studio or of other editors, so a key that does one thing in the default may do something else in another scheme.

To see the schemes, open the Tools menu, choose Options, and then choose Environment and Keyboard. The Mapping scheme list shows the names. Choose a scheme there, and the shortcuts change to match it.

Here is the important part. A scheme is the whole set at once. If you pick a different scheme, every shortcut changes, including the ones you learned in the earlier chapters. Change the scheme only when you have a reason, such as coming from another editor, and expect to relearn some keys.

If you want just one shortcut to be different, you do not need a new scheme. You rebind that one command. The next lesson shows how.

## Try it

1. Open the Tools menu, choose Options, and then choose Environment and Keyboard.
2. Open the Mapping scheme list, and read the names. Do not change anything.
3. Choose Cancel to leave the scheme as it is.
