# Homework: rebind one command

This exercise has you rebind one command, use the new shortcut, and then put the default back. It changes only your computer's settings, so nothing in the practice repository changes.

## Work through these steps in order

1. **Find the command.** Open Options, go to Environment and Keyboard, and type SolutionExplorer in the Show commands containing box, with no space.
2. **Note the current shortcut.** In the default scheme it is {{Ctrl+Alt+L}}. Write it down, because you will need it to put the default back.
3. **Choose a free combination.** Pick a combination you do not use for anything else. Click in the Press shortcut keys box and press it.
4. **Assign it.** If the page reports that the combination is in use, choose a different one. When it is free, click Assign, and then choose OK.
5. **Use it.** Press your new combination. Solution Explorer should open or come to the front. Press it again if the window was already open.
6. **Put the default back.** Open Keyboard again, search for SolutionExplorer, select your new combination, and click Remove. Then press {{Ctrl+Alt+L}} in the Press shortcut keys box, click Assign, and choose OK.

## Check your work

The command runs from your new combination, and {{Ctrl+Alt+L}} opens Solution Explorer again.

~~~spoiler
Any free combination is correct, as long as you use it and then remove it. A combination that works well is one you can reach with one hand, and that the default scheme does not use.

If Visual Studio says the combination is already in use, that is the page doing its job. Choose another.

Rebinding is per computer. If you export your settings after this exercise, the file will include your new shortcut, so remove it first if you do not want it in the file.
~~~
