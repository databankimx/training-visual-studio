# Checklist: pull requests

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You pushed a branch, and opened a pull request on github.com with a title and a description.
- [ ] You opened the same pull request from inside Visual Studio.
- [ ] You read the changed lines on the Files changed tab.
- [ ] You left a comment on a line, and submitted a review.
- [ ] You read the Checks area, and noted what it showed.
- [ ] You closed the homework pull request without merging.
