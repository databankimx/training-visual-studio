# Pull requests in Visual Studio

Visual Studio can show a pull request without a browser. It uses the GitHub sign-in you set up in Chapter 2, so it knows which repository you are working in. Use it when you are already in the editor and want to check a review without switching windows.

Figure 17.2 shows the pull request view in Visual Studio, for the pull request you created in the last lesson. It lists the same title, status, and checks as the website, and it lets you open the changed files in the editor.

![Figure 17.2 - The pull request view in Visual Studio](images/ch17-vs-pull-request.png "width=75%")

*Figure 17.2 - The pull request view in Visual Studio*

To open it, find the pull request for your current branch from the Git menu, or from the GitHub entry in the Git Changes window. Choose the pull request, and it opens in a view that shows its title, description, and checks. Use the website for the discussion, and Visual Studio for the code, which is faster when you need to change a file.

Creating the pull request from Visual Studio works in a similar way, using the same form as the website. Either way, the pull request lives on GitHub, and the review happens there.

## Try it

1. Open your practice solution, and switch to feature/pricing-notes.
2. Find the pull request for the branch from the Git menu, or from the GitHub entry in the Git Changes window.
3. Read its title and checks, and close the view.
