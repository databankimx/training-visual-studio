# 17. GitHub Pull Requests

A pull request is a proposal to merge one branch into another, with a place for people to read the changes, ask questions, and approve them before they reach main. On GitHub, the proposal is the pull request page. It lists the commits, shows every changed line, and collects comments and checks in one place.

This chapter covers the main path, which is creating a pull request on GitHub.com, because most of the team's work happens on the website. It also shows the same steps from Visual Studio, and how to review a pull request and read its checks. Both paths matter, because you will use the website for review and Visual Studio for the code.
