# Appendix: Shortcuts, Commands, and Settings

This appendix is reference. It has no exercises. Use it when you need a key you have forgotten, the name of a command, or the setting behind a behavior.

The shortcut table lists every shortcut the lessons use, with the chapter where each one first appears. Chords, such as Ctrl+K followed by S, are shown as two keycaps with the word then between them.

Microsoft publishes the full default list. Two references are useful:

- [Keyboard shortcuts in Visual Studio](https://learn.microsoft.com/en-us/visualstudio/ide/default-keyboard-shortcuts-in-visual-studio), the online reference.
- A one-page PDF sheet of the same shortcuts, which the shortcut table lesson links to.

Shortcuts can change between Visual Studio versions, and you can change them yourself. If a key does nothing, open Options, go to Environment and Keyboard, and search for the command name. Chapter 24 shows how.
