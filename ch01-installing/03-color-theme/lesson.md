# Color theme

The color theme changes the colors of the whole Visual Studio window. The course's screenshots use the dark theme, so if you pick it too, your screen will match the pictures. You can choose a light theme or the blue theme instead. The lessons still make sense either way.

To change it, press {{Ctrl+Q}} to open Command Search, type Options, and press {{Enter}}. In the Options dialog, open Environment, then General. The Color theme box lists the choices. Pick one, and choose OK.

> **Command Search is the quickest way to any setting.** You will use it throughout the course. The Options dialog is a good place to practice it, because nearly every setting in Visual Studio lives there.
