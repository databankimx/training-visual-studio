# Accounts

Visual Studio uses three accounts in this course. You set them up in Chapter 2 and Chapter 20, not on the first launch.

- **A Microsoft account** signs you in to Visual Studio. Visual Studio offers it at the first sign-in prompt, and you can skip that prompt.
- **A GitHub account** holds the practice repository, and it is where Git sends your work. It is separate from your Microsoft account.
- **GitHub Copilot** uses your GitHub account. Chapter 20 covers signing in to it.

Keeping them separate means that a problem with one does not stop the other. It also keeps the course's practice account apart from any Microsoft account you already use for other things.

If you skipped the sign-in prompt, nothing is wrong. Chapter 2 walks you through creating and signing in to each account, in the order you need them.
