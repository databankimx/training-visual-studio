# 1. Installing and the First Launch

This chapter gets Visual Studio onto your computer and open for the first time. You will install the Community edition with the .NET desktop development workload, work through the prompts that appear on the first launch, meet the start window, and choose a color theme.

Most of this chapter is reading. The last step is a checklist, and it is the one to finish, because the later chapters assume these settings are in place.
