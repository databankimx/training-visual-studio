# Chapter summary

You now have Visual Studio installed and open, with the color theme chosen. Keep these in mind for the rest of the course:

- The course uses the Community edition, with the .NET desktop development workload.
- On the first launch, skip the sign-in prompt and choose Maybe later at the Copilot prompt. Chapter 2 sets up the accounts.
- The start window appears after the prompts, and you can get back to it from the File menu.
- The color theme is in the Options dialog, and Command Search, opened with {{Ctrl+Q}}, finds it.

