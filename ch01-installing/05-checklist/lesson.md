# Checklist: first launch

Work through this list. Each item is something you can see in the window or in a dialog. If an item does not match, go back to the lesson it names before you move on.

- [ ] Visual Studio opens, and you have noted the edition and version from Help, then About Microsoft Visual Studio.
- [ ] The .NET desktop development workload is installed. The setup script confirms it, or you have ticked it in the Visual Studio Installer.
- [ ] At the sign-in prompt you chose Skip and add accounts later, and at the Copilot prompt you chose Maybe later.
- [ ] You have seen the start window, and you know how to get back to it from the File menu.
- [ ] The color theme is the one you chose in the Options dialog.

Chapter 2 creates your Microsoft account, your GitHub account, and the practice repository. You will need both accounts before you reach the GitHub chapters.
