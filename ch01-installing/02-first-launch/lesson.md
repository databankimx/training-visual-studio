# First launch

The first time Visual Studio opens, it shows two prompts. The first offers to sign you in with a Microsoft or GitHub account. The second offers GitHub Copilot. Both can be skipped for now, because you set up your accounts in Chapter 2. After the prompts, Visual Studio shows the start window.

## The sign-in prompt

Figure 1.2 shows the first prompt.

![Figure 1.2 - First sign-in prompt](images/ch01-sign-in-prompt.png)

*Figure 1.2 - First sign-in prompt*

It offers to sign in with a Microsoft account, to sign in with a GitHub account, or to create an account. For this course, choose the link at the bottom, Skip and add accounts later. Chapter 2 walks you through setting up your accounts.

## The Copilot prompt

Next, Visual Studio offers GitHub Copilot Free. Figure 1.3 shows it.

![Figure 1.3 - GitHub Copilot prompt](images/ch01-copilot-prompt.png)

*Figure 1.3 - GitHub Copilot prompt*

Choose Maybe later. Copilot is set up in Chapter 20, after you have your GitHub account.

## The start window

When the prompts are done, Visual Studio shows the start window, which is Figure 1.4. It offers to create a new project, open a project or solution, open a folder or workspace, or clone a repository. You do not need any of them today. To go on without opening anything, choose Continue without code at the bottom right.

![Figure 1.4 - Start window](images/ch01-start-window.png)

*Figure 1.4 - Start window*

Opening a solution is the subject of Chapter 3.

> **If the start window does not appear**, open Visual Studio from the Start menu. Some installs open the last solution you worked on instead. To get to the start window, choose File, then Close Solution. The start window appears when no solution is open.
