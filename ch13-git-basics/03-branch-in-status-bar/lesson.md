# The branch in the status bar

A branch is a line of commits. Your repository starts on a branch called main, and every commit you make adds to whichever branch you are on. The status bar at the bottom of the Visual Studio window shows the name of that branch, with a small branch icon beside it. Figure 13.2 shows the status bar with main selected.

![Figure 13.2 - The status bar with the branch name main](images/ch13-status-bar-branch.png "width=60%")

*Figure 13.2 - The status bar with the branch name main*

The branch name is the first thing to check before you commit. If you are on main when you meant to be on a feature branch, your commit lands in the wrong place. Chapter 14 covers creating and switching branches, and it starts by clicking this name.

Clicking the branch name opens a menu. You can see the other branches from there, and switch to one of them. For now, leave it on main.

## Try it

1. Find the branch name at the bottom of the window, and note it.
2. Click the branch name, and read the menu that opens. Press {{Esc}} to close it without changing anything.
