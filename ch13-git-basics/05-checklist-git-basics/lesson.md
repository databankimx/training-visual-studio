# Checklist: Git basics

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You opened the Git Changes window from the View menu.
- [ ] You opened a changed file from the Changes list, and read the change.
- [ ] You staged one file, and wrote a commit message in the commit box.
- [ ] You committed with Commit Staged, and the commit appeared in the history.
- [ ] You found the branch name in the status bar.
- [ ] You completed the homework, and left one change unstaged.

Chapter 14 covers branches and stashing.
