# Checklist: push, pull, and sync

Work through this list before you go on. Each item is something you did on the screen.

- [ ] You pushed your commits from the Git Changes window, and the count went to zero.
- [ ] You pulled a commit made on GitHub, and saw it in your files.
- [ ] You read the ahead and behind arrows in the status bar.
- [ ] You opened the Output window, and read a Git error from the bottom up.
- [ ] You completed the homework, and resolved a rejected push.
