# 15. Branches and Stashing

Chapter 14 committed changes to main, the branch your repository starts on. In real work, you rarely want every change on main as you go. A branch is a separate line of commits. You make a branch for one idea, work on it, and merge it back when it is ready, or throw it away if it was a dead end. Main stays in a state you can trust while you experiment.

This chapter covers creating a branch, switching between branches from the status bar, and stashing. Stashing sets aside unfinished changes, so you can work on something else and come back to them later.
