# 15. Pushing, Pulling, and Syncing

So far every commit has stayed on your computer. Git is distributed, which means each copy of a repository holds its own full history, and the copies exchange commits when you ask them to. Pushing sends your commits to GitHub. Pulling brings commits from GitHub to your computer. Syncing does both.

This chapter uses your copy of the practice repository and its counterpart on GitHub. You will push the commits from Chapter 13 and 14, pull a change made on the website, and read the Output window when Git reports a problem.
