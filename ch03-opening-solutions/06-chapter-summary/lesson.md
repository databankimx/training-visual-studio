# Chapter summary

The practice solution is on your computer and open in Visual Studio. Keep these in mind for the rest of the course:

- Open the solution with File, then Open, then Project/Solution. Open Folder is the alternative for a folder with no solution.
- A solution holds projects, and the Solution Explorer shows both.
- Go to All, opened with {{Ctrl+T}}, finds any file by its name.

```quiz
What does a solution contain?
◉ One or more projects
→ That is what a solution holds. The practice solution holds three.
○ One file and nothing else
→ A solution is a container that holds projects, so it can hold several.
○ Only the NuGet packages
→ Packages belong to projects. The solution holds the projects.
```

```quiz
Which keys open Go to All, to find a file by its name?
○ Ctrl+Q
→ Ctrl+Q opens Command Search, which finds commands and settings.
○ Ctrl+Shift+F
→ That searches the text inside files, which Chapter 4 covers.
◉ Ctrl+T
→ That is Go to All. Type part of the file name, and pick the file.
```

```quiz
Which file type is the solution file that Visual Studio opens to load the whole set of projects?
◉ .sln
→ That is the solution file. It lists the projects that belong together.
○ .cs
→ A .cs file holds source code for one class, not the solution.
○ .csproj
→ A .csproj file describes one project. The solution file is the one that lists the projects.
```
