# Finding files

There are two quick ways to find a file in the solution. Go to All finds any file by its name, wherever it sits. The Solution Explorer search box finds items in the tree you can already see.

## Go to All

Press {{Ctrl+T}}, type part of the file name, and watch the list. Visual Studio narrows it as you type. Use the arrow keys to pick a file, and press {{Enter}} to open it.

Figure 3.5 shows Go to All with a search typed in.

![Figure 3.5 - Go to All results for a file name](images/ch03-go-to-all.png "width=75%")

*Figure 3.5 - Go to All results for a file name*

Go to All does not need the Solution Explorer to be open, and it does not need you to know which project the file belongs to. It is the fastest way to reach a file you know the name of.

## The Solution Explorer search box

The search box at the top of the Solution Explorer is labeled Search Solution Explorer. Press {{Ctrl+;}} to move the cursor into it, or select it with the mouse. Type part of a name, and the tree shows only the matching items.

Clear the search box to see the whole tree again. Searching does not change any file, so it is safe to try.
