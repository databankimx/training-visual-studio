# Checklist: solutions and files

Work through this list before you go on. Each item is something you can see in the Visual Studio window or in a dialog.

- [ ] The practice repository is on your computer, in C:\Development\training-visual-studio-practice.
- [ ] You opened PracticeSolution.sln with File, then Open, then Project/Solution.
- [ ] The Solution Explorer shows the solution and its three projects: Pricing, Pricing.Tests, and PriceReport.
- [ ] You can say what a solution is, and what a project is.
- [ ] You found a file with Go to All, and you opened it.
- [ ] You cleared the Solution Explorer search box after you used it.
- [ ] You opened the Add menu on a project, and read what New Item, Existing Item, and New Folder do.
- [ ] You created a folder and a class in it, and read the namespace Visual Studio gave the class. You removed both afterward.

Chapter 4 covers the windows around the editor, how to move and float them, and how to find text across the solution.
