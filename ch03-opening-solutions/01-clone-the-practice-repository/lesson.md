# Cloning the practice repository

Your practice repository lives on GitHub, under your account. Before you can work on it, you need a copy on your computer. Visual Studio makes that copy for you from the start window.

Figure 3.1 shows the Clone a repository option on the start window.

![Figure 3.1 - Clone a repository on the start window](images/ch03-clone-repository.png "width=75%")

*Figure 3.1 - Clone a repository on the start window*

If the start window is not showing, choose File, then Close Solution, and it appears. Choose Clone a repository. In the box for the repository location, paste the web address of your practice repository. It looks like this, with your GitHub username and the repository name you chose in Chapter 2:

`https://github.com/YOUR-USERNAME/training-visual-studio-practice.git`

Replace YOUR-USERNAME with your GitHub username. If you named your repository something other than training-visual-studio-practice, change the name in the address to match.

Choose a location for the copy. This course uses C:\Development, so the copy goes in C:\Development\training-visual-studio-practice. Choose Clone, and wait for it to finish.

If Visual Studio asks you to sign in to GitHub, sign in with your personal GitHub account, and allow the access it asks for. Visual Studio remembers the sign-in for the later steps.

When the clone finishes, Visual Studio may open the folder rather than the solution. Either way is fine. The next lesson opens the solution itself.

> **Keep the copy tidy:** the practice repository is yours to change, but the course folder you installed earlier is not. Do your work in training-visual-studio-practice, and leave the course folder alone.
