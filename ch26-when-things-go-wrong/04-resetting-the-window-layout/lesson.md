# Resetting the window layout

Sometimes a window ends up in the wrong place, or it disappears. You may have closed a panel, dragged a window onto a second monitor that is no longer connected, or undocked something you cannot find again. Resetting the window layout puts every window back to its default position.

Open the Window menu, and choose Reset Window Layout. Visual Studio asks you to confirm, because it closes the windows and puts them back where they started.

A reset affects window positions only. It does not change your settings, your shortcuts, or your solutions. Chapter 23 explains how to reset the settings, which is a different action and needs more care.

## Try it

1. Open the Window menu, and read the Reset Window Layout command.
2. Do not choose it unless a window is lost. If you do, confirm the prompt, and then open the Output window again with {{Ctrl+Alt+O}}.
