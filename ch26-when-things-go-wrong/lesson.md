# 26. When Things Go Wrong

Most days Visual Studio does what you expect. When it does not, the first question is where to look. Visual Studio keeps several places that explain what it is doing: the Output window, the Error List, and a log file called the Activity Log. When the window itself misbehaves, you can reset the layout, or start Visual Studio in safe mode, which runs it without extensions so you can see whether one of them is the cause.

This chapter takes these in the order you are likely to need them. Start with the Output window, because most problems first show up there.

Read before you share. The Activity Log and the settings files can both contain folder paths and account names from your computer. Check a file before you send it to anyone.
