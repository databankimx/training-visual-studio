# Checklist: when things go wrong

Work through this list before you go on. Each item is something you did on the screen or at a command prompt.

- [ ] You opened the Output window, and chose a source from the Show output from list.
- [ ] You filtered the Error List, and went to the line of one entry.
- [ ] You found ActivityLog.xml, and searched it for an error.
- [ ] You read the Reset Window Layout command, and understood what it changes.
- [ ] You read the safe mode steps, and found the devenv path for your edition.
