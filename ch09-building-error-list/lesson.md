# 9. Building and the Error List

Building turns your source files into a program. The compiler reads every file in the solution, checks it for mistakes, and writes the output to a folder. When the build fails, the errors tell you what to fix. This chapter covers the Build menu, the Error List and Output windows that report the results, the Debug and Release configurations, and how to read a list of errors so you fix the right one first.

The lessons use the practice solution. The homework adds a file with two deliberate errors, and asks you to fix them in the order the build reports them.
